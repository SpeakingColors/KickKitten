**Test build (v0.1.1: Reference Match, full Render tab, pitch dots follow the Tail/Start/Sweep/Curve knobs, readable pitch labels).** Kick Kitten is a free and open source trance kick maker (VST3 and Standalone). It was built and checked by numbers (engine matches the mockup, state save and load, all 21 factory presets render clean), but it has **not been tuned by ear yet** and has not been tested in real DAWs. Please report problems as GitHub issues.

One zip, everything offline:
- Windows: `KickKitten-Setup.exe` (installer with uninstaller)
- macOS: `KickKitten-macOS.pkg` (installs the plugin, the standalone app and "Uninstall Kick Kitten")
- Linux: Flatpak extension for Flatpak DAWs, and a plain `.vst3` tarball
- PDF manual, `INSTALL.txt`, `SHA256SUMS`

The installers are not signed, so Windows and macOS will warn; `INSTALL.txt` explains the clicks. No telemetry, no network access, nothing collected.
